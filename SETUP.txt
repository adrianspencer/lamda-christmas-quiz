LAMDA Christmas Quiz — test-results preview

Update the test-results branch with index.html, assets/ and functions/api/.
Both game.js and lobby.js belong in functions/api/. The stress-test folder
contains the separate contestant simulator and its instructions.

For an existing working preview, retain its D1 database and host PIN.
For a NEW, empty preview database, bind it to the Pages preview as DB,
apply schema.sql and deploy. Open the preview with /?host=1 once to create
the host row. Before signing in, the database administrator must provision
a PIN for that row (the existing set_pin.sql provisions the project's
previously configured PIN). Open /?host=1 again and enter the PIN.
schema.sql initializes an empty database. It does not migrate older tables.

Players join at the preview root. The host starts play, marks answers,
reveals each answer and advances through 25 questions to final rankings.
